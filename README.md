# SmartBatteryOptimizer

IP-Symcon-Modul zur börsenpreisabhängigen Batterieeinspeisung mit PV-Prognose, lernendem Nachtverbrauch und Unterstützung mehrerer PV-Flächen.

## Version

**1.1.2**

## Dokumentation

Die ausführliche Erklärung aller Konfigurationspunkte befindet sich unter:

- [Konfiguration](docs/Konfiguration.md)

## Installation

Das ZIP enthält direkt `SmartBatteryOptimizer/`, `library.json`, `README.md` und die Dokumentation. Vor Aktivierung der Automatik sollte der berechnete Plan zunächst mit deaktivierter Automatik geprüft werden.
