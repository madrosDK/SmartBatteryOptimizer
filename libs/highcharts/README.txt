Optionales Highcharts

Falls Highcharts zusammen mit dem Repository bereitgestellt werden darf, kann die Datei hier unter folgendem Namen abgelegt werden:

highcharts.js

SmartBatteryOptimizer sucht in dieser Reihenfolge:
1. <Repository>/libs/highcharts/highcharts.js
2. <IP-Symcon-Kernelverzeichnis>/highcharts/highcharts.js
3. Falls beides fehlt: integrierte HTML/CSS-Fallback-Balkengrafik

Das Modul kopiert oder verändert keine Dateien im Installationsverzeichnis.
